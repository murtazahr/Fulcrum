\section{System and Threat Model}
\label{sec:threat}

We define a passive, honest-but-curious adversary against a DP-protected
federated learning system. The threat model is deliberately narrow: by
requiring the attack and defense to operate within the same assumptions,
we preclude hidden scope changes between the two contributions.

\subsection{System Model}
\label{sec:system-model}

A federation consists of $n$ clients $\mathcal{P} = \{P_1,\ldots,P_n\}$
arranged in a topology $\TOPO=(\mathcal{P},E)$ that determines which
pairs of clients communicate during aggregation. Each client $P_i$ holds
a local dataset $\Dset_i$ inducing class distribution
$\Delta_i \in \Delta(\mathcal{C})$ over class set $\mathcal{C}$ of size
$K=|\mathcal{C}|$. Clients are partitioned into organisational groups
by a labelling $\omega:\mathcal{P}\to[k_{\mathrm{org}}]$. Training proceeds
for $\Tmax$ rounds; at round $t$, each client transmits an updated
parameter vector $\theta_i^{(t)}$ produced by local DP-SGD with
per-client noise scale $\sigma_i$.

Throughout we adopt the standard cross-silo
assumption~\cite{wang2021fieldguide} that client datasets are disjoint,
so no two clients share training records. Aggregation follows
FedAvg~\cite{mcmahan2018dpfedavg} for centralised hierarchical settings
and decentralised gossip~\cite{hegedus2021decentralized} for
peer-to-peer topologies; both reduce to weighted averages of client
parameter vectors.

\subsection{Adversarial Model}
\label{sec:adv-model}

The adversary $\Adv = (\KNW, \OBS, \mathcal{I}, \mathcal{R})$ is
specified by four components.

\paragraph{Knowledge $\KNW$.} The adversary knows: (i)~the topology
$\TOPO$; (ii)~the organisational labelling $\omega$; (iii)~all public
protocol parameters (DP budget $\eps$, noise schedule
$\{\sigma_j\}$, model architecture, training schedule). The adversary
\emph{does not} know any client's dataset $\Dset_i$ or its induced
distribution $\Delta_i$. We treat $\KNW$ as a configuration constant of
the experiment, conditioning all probabilistic claims on it.

\paragraph{Observation $\OBS$.} The adversary observes the tensor of
transmitted parameter updates,
$\Theta = \{\theta_i^{(t)} : i \in [n], t \in [\Tmax]\}$, plus
communication metadata. This corresponds to a passive infrastructure
observer (\eg curious cloud aggregator, network-level observer with
broken or absent transport encryption) or a curious aggregator. The
adversary's view is fixed by the protocol; the adversary cannot inject
traffic or modify messages.

\paragraph{Inference goal $\mathcal{I}$.} For a designated sensitive
class set $\Cs \subset \mathcal{C}$, recover for each client $i$ the
sensitive-class concentration
\[
p_i \;=\; \Delta_i(\Cs) \;\in\; [0,1].
\]
This recovers either a single sensitive proportion (binary tasks like
Fed-Heart-Disease) or a designated rare-class proportion (multiclass
tasks like Fed-ISIC2019 melanoma; CIFAR-10). The metric is
\emph{calibration loss} $L_{\text{cal}} = \frac{1}{n}\sum_i (\hat p_i - p_i)^2$;
\emph{attack lift} relative to the constant-mean baseline
$\bar p = \frac{1}{n}\sum_j p_j$ measures whether the adversary extracts
information beyond the federation aggregate.

\paragraph{Restrictions $\mathcal{R}$.} Honest-but-curious. The adversary
follows the protocol, cannot perturb $\theta_i^{(t)}$ before observation,
cannot inject training data, cannot collude with clients, and cannot
adaptively select compromise targets. Active adversaries, malicious
aggregators, and Sybil attacks are out of scope.

\subsection{Independence Assumptions}
\label{sec:independence}

Two assumptions structure the analysis.

\textbf{(IA1) DP-SGD noise independence.} Per-round Gaussian noise
$\xi_i^{(t)} \sim \mathcal{N}(0, \sigma_i^2 C^2 I)$ is independent
across $(i,t)$ pairs. Standard~\cite{abadi2016dpsgd}.

\textbf{(IA2) Disjoint client datasets.} For $i \neq j$,
$\Dset_i \cap \Dset_j = \emptyset$. This is the standard cross-silo
assumption~\cite{flamby2022,sheller2020medicine}: hospitals enrol
distinct patients, sites collect distinct samples. Cross-device FL
where the same individual contributes to multiple clients (rare in
practice) would require strengthened conditions; we flag this as a
limitation.

Aggregation is FedAvg or its hierarchical/gossip variants and is
\emph{not} treated as a privacy mechanism in our threat model: the
adversary observes per-client updates before aggregation. Under secure
aggregation~\cite{bonawitz2017secagg} this changes; we evaluate that
regime as an extension experiment (\S\ref{sec:experiments-sa}).

\subsection{Reference Adversaries}
\label{sec:reference-adv}

We isolate the contribution of structural information by comparing four
reference adversaries differing only in $\KNW$:

\begin{itemize}[topsep=2pt,itemsep=2pt,leftmargin=*]
\item $\Adv_0$: random/constant-mean baseline. Outputs the federation
  mean $\bar p$ for every client. Reference for attack lift.
\item $\Adv_1$: parameter-only.
  $\KNW = \{\sigma_j\}$, $\OBS = \Theta$.
  Recovers $\hat p_i$ from parameter sequences alone. This is the
  ``no topology, no organisation'' Melis-style adversary~\cite{melis2019exploiting}.
\item $\Adv_2^{\text{topo}}$: structural-only.
  $\KNW=\TOPO$, $\OBS=\Theta$.
  Recovers $\hat p_i$ from parameter sequences \emph{plus} structural
  features (degree, hierarchical depth, distance to root). Isolates
  the marginal value of topology.
\item $\Adv_2^{\text{org}}$: label-only.
  $\KNW=\omega$, $\OBS=\Theta$.
  Recovers $\hat p_i$ from parameter sequences \emph{plus}
  organisational labels.
\item $\Adv_2^{\text{full}}$: full knowledge.
  $\KNW = (\TOPO,\omega,\{\sigma_j\})$, $\OBS=\Theta$.
  The adversary of interest.
\end{itemize}

The \emph{topology contribution} is $L_{\text{cal}}(\Adv_1) - L_{\text{cal}}(\Adv_2^{\text{full}})$;
the marginal contributions of structure and label are obtained by
comparing $\Adv_2^{\text{full}}$ against the corresponding partial
adversary. The \emph{IID-null condition} arises when the partitioning
makes $p_i$ constant across clients: every adversary's calibration
loss equals $\Var(p)$, and attack lift is identically zero. We use
this condition as a sanity check throughout.
