# Manuscript

ACM TOPS submission, `acmart` class (`acmsmall` journal format, single column).

## Build

```bash
tectonic -X compile main.tex
```

Tectonic runs BibTeX internally. With a classical toolchain:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Files

| file | role |
|---|---|
| `main.tex` | the paper |
| `references.bib` | bibliography, ACM-Reference-Format |
| `acmart.cls`, `ACM-Reference-Format.bst` | ACM template, unmodified |
| `figures/` | generated by `../fulcrum/make_figures.py` |

## Notes

`\documentclass[acmsmall,review]{acmart}` gives line numbers for review. Add
`anonymous` if the venue is double-blind; drop `review` for the camera-ready.

Figures are authored at exactly the `acmsmall` text width (395.82pt = 5.48in) and
included at natural size, so they must be regenerated if the class or format
changes. Rescaling a figure through `\includegraphics[width=...]` rescales its
fonts with it.
